# to-do-list

    A simple application for me to keep track of my to-do's.

    ## Files

    - index.html: the page
    - styles.css: the looks
    - js/data.js: the tasks array, and saving them so they survive a refresh
    - js/render.js: drawing the list on the page
    - js/app.js: wiring the buttons to the functions

    ## User stories

    - [ ] As a user, I see the app's page with a heading, an input, an add button, and an empty list.
    - [ ] As a user, I can type a task and add it, and it appears in the list.
    - [ ] As a user, I can mark a task complete, and it shows as done.
    - [ ] As a user, I can see how many tasks are left, and the number updates as I work.
    - [ ] As a user, my tasks are still there when I refresh the page.
